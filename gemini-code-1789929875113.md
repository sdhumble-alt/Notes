# A Humble Note Builder
**Version:** 1.0.0 (Release)
**Author:** Steven Humble
**Suite:** "A Humble..." Educational Web Applications

## Overview
**A Humble Note Builder** is a client-side, single-page web application designed specifically for educators. It solves the formatting frustrations of standard word processors by providing a free-form, mathematically scaled canvas optimized for creating guided notes, graphic organizers, and Interactive Student Notebook (ISN) inserts. 

The application ensures that what is designed on the screen scales perfectly to physical paper, offering specialized tools like automated Cornell Notes layouts, smart alignment guides, and rich-text editing with built-in scientific symbols.

---

## Core Features

### 1. Precision Canvas & Layout Engine
* **Custom Dimensions:** Built-in presets for Standard Letter (8.5" x 11") and Composition Notebooks (6.25" x 8.5" & 7" x 9"), plus custom inch-based inputs.
* **Orientation:** One-click toggling between Portrait and Landscape.
* **Intelligent Scaling:** If paper dimensions are changed mid-project, the app can optionally auto-scale all elements (positions, widths, heights, and font sizes) proportionally to fit the new canvas.
* **Smart Snapping:** Elements automatically snap to a customizable pixel grid or to the edges/centers of other elements via magenta Smart Guides.

### 2. Element Library
* **Blank Boxes:** Resizable containers that support internal patterns (Writing Lines, Graphing Grids) and inline Header Labels that automatically split the top stroke.
* **Text Blocks:** Borderless floating text zones.
* **Data Tables:** Highly customizable grids where rows and columns can be scaled, and individual cells can be formatted independently or globally.
* **Images:** Local file uploads that scale proportionally.
* **Page Numbers:** Auto-calculates the bottom-right corner of the safe zone to drop a 9pt page number block for student reference.

### 3. Pedagogical Templates
* **Cornell Notes:** Instantly generates a mathematically scaled, 4-part layout (Topic, Cues, Notes, Summary) that respects the current paper size and safe margins.
* **Frayer Model:** Auto-generates a 5-part vocabulary matrix (Definition, Characteristics, Examples, Non-Examples, Center Word).

### 4. Advanced Text & Formatting
* **Global Typography:** Select a master font (including standard academics, monospace, and dyslexia-friendly Comic Sans) that applies to the entire document.
* **Rich Text Toolbar:** Bold, Italic, Underline, Strikethrough, and Horizontal/Vertical alignment controls.
* **List Engine:** Auto-incrementing Bullet, Numbered, Outline (I, A, 1, a), and Checkbox (`☐`) lists that automatically generate perfect hanging indents.
* **Scientific Notation:** Dedicated insertion panels for Greek letters and Math symbols, plus single-click Subscript and Superscript conversion using Unicode mapping.

### 5. Project Management & Export
* **.humblenote Files:** Save and open ongoing projects as lightweight local JSON files.
* **History Stack:** Full Undo/Redo tracking for all canvas actions.
* **Local Storage:** The application remembers the last used paper size, custom dimensions, orientation, and font family between sessions.
* **High-Fidelity PDF Export:** Utilizes `jsPDF` to generate resolution-perfect PDF files. When exporting a canvas smaller than 8.5" x 11", the app automatically renders 24px cut-lines at the document bounds to guide paper cutters.

## Technical Architecture

The application is built entirely with vanilla web technologies, requiring no build steps, external databases, or server-side rendering.

* **Frontend Structure:** HTML5 & CSS3, utilizing CSS Grid and Flexbox for the interface layout.
* **Rendering Engine:** The core workspace relies on the HTML5 `<canvas>` API (`CanvasRenderingContext2D`) for all element drawing, text wrapping, and bounding-box calculations.
* **State Management:** A central `state` object tracks all elements, selected IDs, zoom levels, and paper configurations. History is maintained by stringifying the state array and pushing it to a `historyStack`.
* **Dependencies:**
  * **Tabler Icons:** Imported via CDN for lightweight, scalable UI iconography.
  * **jsPDF:** Imported via CDN (`jspdf.umd.min.js`) to handle exact-dimension PDF generation bypassing browser-level print margin quirks.
  * **Google Fonts:** External link to load specific display fonts (e.g., Bangers).

## Data Structure (.humblenote format)
Projects are saved as serialized JSON strings. The root object contains three primary nodes:

```json
{
  "paper": {
    "widthInches": 6.25,
    "heightInches": 8.5
  },
  "font": "Arial, sans-serif",
  "elements": [
    {
      "id": "a1b2c3d4e",
      "type": "box | text | table | image",
      "x": 120,
      "y": 240,
      "w": 300,
      "h": 150,
      "text": "Parsed canvas text\nWith line breaks",
      "format": {
        "bold": false,

        "strike": false,

      "borderWidth": 2,
